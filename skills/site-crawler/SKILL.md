# site-crawler — 本地有界整站抓取（静态 HTML → markdown）

> **是什么**：递归抓取一个站点，去重规范化 URL，提取正文转 markdown，按原站结构落盘为本地素材。不是 Firecrawl 等价物：无 JS 渲染、无代理池、无 API 服务；不依赖付费 API，但依赖本身（requests、trafilatura）有安装与维护成本，"无 API 调用费"不等于零成本。
> **来源**：保留源包的 Hermes Agent (GT) 署名与 MIT 许可；本公开版增加通用使用说明和验证材料。
> **什么时候用**：单页提取不足，需要批量取材静态 HTML 文档站、课程站或文章列表站时。规模按任务需要选取，不默认全量。

## 前置依赖

- Python 3.10+ + requests + trafilatura（依赖范围见 `requirements.txt`）。先确认当前环境可导入，缺依赖时如实说明、由用户决定是否安装；不默认执行 pip 安装：
```bash
python -c "import requests, trafilatura"
```

运行前确认站点与栏目范围、请求预算和本地输出位置。只处理允许访问和抓取的材料，遵守站点规则；本脚本不自动解析robots.txt、不提供登录或绕过访问限制的能力。URL规范化会去除fragment、尾斜杠和内置tracking参数；若某站依赖这些信息区分内容，应先确认规则适合，不能把此工具当成逐URL无损镜像。

## 核心脚本

`scripts/crawl_site.py` —— 命令行调用：

```bash
python <skill_dir>/scripts/crawl_site.py \
  --url https://docs.example.com/ \
  --out ./workspace-crawl/example-docs/ \
  --max-pages 50 --max-requests 150 --delay 0.5
```

输出写到工作区素材目录；写 Obsidian 库须另行授权并按摄入技能处理，不是本脚本的默认目的地。

### 参数

| 参数 | 默认 | 说明 |
|------|------|------|
| `--url` | 必填 | 起始 URL |
| `--out` | 必填 | 输出目录（按主机名建子目录） |
| `--max-pages` | 100 | 成功提取页数上限（不是请求总数上限） |
| `--max-requests` | 3×max-pages | 请求总预算：失败请求、无正文页、重定向每一跳都计数 |
| `--max-consecutive-errors` | 5 | 连续失败达到该数立即中止（退出码 2） |
| `--delay` | 0.5 | 每次请求前的间隔秒（礼貌爬取） |
| `--same-host-only` | 始终限域 | 兼容保留标志；抓取范围始终限于起始主机，不能借此关闭限域 |
| `--allow-subdomains` | 关 | 显式允许起始主机的子域；默认严格同主机（netloc 精确匹配） |
| `--skip-prefix` | 无 | 跳过含指定子串的 URL（可多次） |

### 输出与边界

- 每页一个 `.md` 文件，路径镜像可安全落盘的站点目录结构（`/docs/intro` → `<out>/<host>/docs/intro.md`）；普通可信本地输出目录下，目录分段清理并限制长度，解析后越出目标目录的路径拒写，首行注释保留来源 URL
- URL 规范化去重（去 fragment、去 tracking 参数：utm_*/ref/spm 等）；保留的非 tracking query 会编入文件名（`?id=1` / `?id=2` 落为两个不同文件），路径冲突（如 `/foo` 与 `/foo.html`）时以规范化 URL 的 sha1 前 8 位后缀区分——每个规范化 URL 唯一映射到一个输出文件
- **不覆盖已有文件**：目标路径被其他 URL 占用或磁盘上已存在旧文件时，改走后缀新路径；仍冲突则跳过并标注 `[CONFLICT]`，重抓旧目录不会破坏旧结果；实际创建使用排他模式，检查后若文件被新建也不会覆盖
- 重定向逐跳手动跟随：每一跳发请求前先做范围检查（HTTP(S)/主机/子域/二进制/skip-prefix）；跨主机或越界的跳转目标不发请求，标注 `[SKIP-REDIRECT]`
- 自动跳过：图片/PDF/zip 等二进制资源、`mailto:`、`javascript:`、重复斜杠
- 页面无正文时跳过并在日志标注（`[NO-TEXT]`）；该请求仍计入总预算
- 退出码：0 = 队列走完或到达成功页上限且无错误；1 = 有请求/写入错误；2 = 连续失败中止或请求预算截断（结果可能不完整）

## 流程

1. **按任务定规模**：从小样开始（`--max-pages` 取 5 只是常见起点，不是固定配方；按站点风险设定），检查输出结构后再决定是否扩大
2. **扩大运行**：按预计时长运行；如宿主支持后台执行，使用其原生完成通知并只在必要时读取进度；不要假设所有宿主都支持同一组参数；请求预算耗尽或连续失败达阈值会自行停止
3. **抓取结果只是素材**：抓取结果默认留在本地素材目录。用户明确要求写入 Obsidian 时，沿其当前摄入流程和目标库 README/SCHEMA 处理；不要求安装某个特定摄入Skill，也不复制一套笔记规则

## Pitfalls

- **别拿它爬外链站**：默认严格同主机；子域须显式 `--allow-subdomains`；跨站内容使用当前环境的单页提取能力按需处理
- **动态渲染站抓不到**：JS 渲染的内容 trafilatura 提取不到——先用当前环境的单页提取能力验证有正文再决定批量
- **反爬要区分状态码**：429 是速率限制（加大 `--delay`、缩小范围再试）；403 是访问策略限制，加 delay 无效，换合规来源或放弃，不硬闯
- **上限语义分清**：`--max-pages` 只封顶成功提取页；失败/无正文/重定向不占它，请求总数必须由 `--max-requests` 兜底
- **重抓旧目录**：覆盖保护意味着旧文件原样保留、新内容落为带后缀的文件；需要干净重建时换一个输出目录，别指望脚本原地更新

## Verification

- [ ] 试跑后输出目录结构与源站路径对应，`<!-- source: -->` 可回链
- [ ] query/path 变体（`?id=1` vs `?id=2`、`/foo` vs `/foo.html`）落为互不覆盖的不同文件
- [ ] 已有输出目录中的旧文件未被改写（覆盖保护生效）
- [ ] 跨主机/子域跳转按策略标注 `[SKIP-REDIRECT]` 且未发出对应请求
- [ ] 汇总行 `requests=N/预算` 不超预算；连续失败场景退出码为 2
- [ ] `[NO-TEXT]` 未大量出现（否则说明站点动态渲染或反爬，停止扩大）
