# personal-notes — 保留原话的个人笔记

个人笔记可能包含用户随想、摘录和整理，不能仅因被记录就推定全部原创。目标以用户已明确的笔记路径为准；已有可靠路径时直接使用，不从相似文件名推断。路径不明且会影响写入对象时先确认。沿用目标笔记的日期结构与本地元数据规则，不预设某个用户名或磁盘位置。外部视频或文章的完整摄入使用当前环境已有的摄入能力，不把普通记一句话自动升级为完整摄入。

## 何时使用

- 「写入心理学笔记」「记到个人笔记」等追加请求。
- 「深入分析这段」「注解用这个视频的内容总结」等注解写入或修改请求。
- 为已记录条目补来源或核对指定来源的解读。

## 先按请求选择注解深度

1. 普通「记入笔记」默认 **原话＋适量注解**。温柔、自然地说明这句话的意思或可能帮助理解的角度，够用即止；不照搬旧长注解的篇幅，不强制追溯全部创伤、家庭经历或行为因果，不凑关联数量。
2. 用户明确要求深入分析时，保留与问题相称的深度、必要上下文和有据分析，不为减少调用压缩成敷衍短句。
3. 用户明确指定视频、文章等来源作注解时，先读取已定位且可核的原文或转写；没有可用材料才提取或转写必要来源。引用、总结和解释忠实该来源，解释与用户原话分开。无法取得关键来源时说明缺口，不凭印象冒充读过。指定来源不自动要求长注解；是否展开仍由请求决定。
4. **用户原话保持逐字不变**，包括其标点和措辞，不默默纠错或润色。明确要求润色时另写「整理表达」，保留原文；明确要求替换或重写已有注解时，只改对应注解。AI注解不得冒充用户的亲身感悟、第一人称自问或确定诊断；可能解释明确用「可能」「可以这样理解」等相称表达。

## 定向读取与关联

- 先复用当前任务已确认的目标、日期、来源及有关上下文。读取 frontmatter 的 `updated`、当日日期块或新日期插入点，以及完成本条所需的局部正文。已够判断就执行，不每条都读前80行再读160行，不遍历长笔记或全库。
- 沿用现有日块格式和排序；尚无约定且用户授权创建记录时，可采用 `**YYYY-MM-DD**` 并将新日块置于旧日块前。日期按当前本机日期或用户明确指定的记录日期决定，同日多条合在既有日块内，不另造同日标题。
- 核当日是否已有同一原话；重复请求已有条目时默认不再次追加，回执如实说明。用户明确要求再次记录或重写注解时按该请求处理，不误删既有记录。
- 心理内容不一律先搜库。需要解释某个概念、核实既有说法或寻找关联且当前上下文不够时，才在已知心理学范围用准确标题、关键词或指针定向查找，再读候选的必要段落。
- 关联只选最贴切且已核内容及目标存在的笔记或旧条目；没有可靠关联可以不加。不得凭标题猜含义或为配齐数量扩大检索。目标可能有歧义或关键事实不足时只补决定该点的材料。

## 写入与核验

1. 每条原话后紧跟自己的 `> 注解：` 引用块，多段注解的各行保留引用格式，不另起与原话脱节的标题。来源和实际核过的关联可放在对应注解内；不把来源全文、检索过程或治理流水塞进笔记。
2. 沿当前官方受支持的编辑工具修改已读、唯一且可靠的锚点。若 frontmatter 的 `updated` 与当日插入点同处一个已读的短连续片段，用一次明确 `patch` 同时完成追加和 `updated` 变更；保留片段内其他字段和原正文。`updated` 按实际修改的本机日期更新，记录日期可以与它不同。不为了合并操作扩大读取或整篇覆盖。
3. 锚点相距过远、工具不支持安全批量或前像发生并发变化时，保留必要分步；可在现有工具支持下顺序批处理，并按每一步真实结果停止失败步骤之后的写入。先重新核对受影响前像，不强行模糊替换、不绕过保护；必要的审批仍走官方入口。
4. 写后回读本次插入片段及日期字段，核原话、注解/来源、当日日期和 `updated`，检查同日重复条目或标题。用工具实际差量核旧文及其他字段未被触碰；必要时定向查对应旧片段，不每次再读整篇。不把“写入调用返回成功”单独作为完整核验。
5. 超时、未知副作用或部分失败先对账已发生的写入，不盲目重放；已追加但日期未改等部分完成如实保留，并只补准确未完。恢复须核当前内容与本次前像，避免覆盖他人新写入。无法可靠核验时明确剩余，不虚报全部完成。
6. 完成后给简洁真实的最终回执：写到哪里、已完成什么、必要限制或准确未完。普通网关任务不发中间工作流；失败或部分完成仍交真实最终说明，不丢失必要结果。

## 来源教训与摄入衔接

指定来源时的反向误读案例见 `references/annotation-source-lesson.md`；需要核这种风险时再加载，不作为每条普通短记的必读前置。用户后补来源时，以所指定来源核对应注解，而非抹去原话或推断用户本人心理动机。

用户要求或确认完整摄入来源后，再使用当前环境已有的摄入能力完成确实需要的转写、笔记和受影响索引；引用已完成且仍适用的摄入材料，不重复提取。同步个人注解只覆盖用户要求的条目与来源解释。
